# Sistema de Chat en Tiempo Real

# Descripción
Este proyecto implementa un sistema de chat en tiempo real utilizando Go y WebSockets.

# Tecnologías
- Go
- WebSockets
- JSON
- Git / GitHub

# Funcionalidades
- Registro de usuarios
- Envío de mensajes
- Recepción en tiempo real
- Gestión de conexiones

# Instalación

```bash
git clone https://github.com/GaBiT0o0/Sistema-de-Chat
cd Sistema-de-Chat
go run main.go
